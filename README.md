# Método Rose Oliveira

Landing page do Método Rose Oliveira em Next.js, publicada em [metodoroseoliveira.vercel.app](https://metodoroseoliveira.vercel.app).

## Desenvolvimento

```bash
npm ci
npm run dev
```

Verificação: `npm run typecheck`, `npm run lint` e `npm run build`.

O repositório contém somente os arquivos de mídia utilizados pela página. O vídeo otimizado está em `public/video-rose-leve.mp4`; os originais enviados permanecem fora do Git. O checkout usa o link fornecido pelo responsável pelo produto. Veja `ASSETS-PENDENTES.md` para os conteúdos ainda aguardando comprovação ou substituição.

O projeto Vercel está conectado à branch `main` deste repositório.
